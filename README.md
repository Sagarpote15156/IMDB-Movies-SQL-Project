Project Title:-
IMDB Movies Database Analysis using SQL

📝 Short Description:-
A structured relational database project built using SQL to analyze IMDB movie data, including movies, directors, genres, and ratings. The project demonstrates advanced querying techniques to extract meaningful insights such as top-rated movies, genre trends, and director performance.

🎯 Purpose:-
To design a relational database for movie data
To analyze movie ratings, genres, and popularity
To practice real-world SQL queries and data relationships
To generate insights useful for decision-making in the entertainment industry

🛠️ Tech Stack:-
SQL (MySQL / SQL Server) – Querying & database design
DBMS – Database management
ER Modeling – Database structure design

📂 Data Source:-
IMDB-style dataset (movies dataset)

Contains:
Movie Title
Director
Genre
Rating
Release Year
Data is structured into multiple relational tables

🌟 Features / Highlights:-
📌 Designed normalized relational database schema
🔗 Implemented Primary Keys & Foreign Keys
📊 Created multiple tables (Movies, Directors, Ratings, Genres)

🔍 Performed complex SQL queries using:-
JOINs (INNER, LEFT)
GROUP BY & HAVING
Subqueries
Aggregate functions (AVG, COUNT, SUM)
📈 Key Analysis Performed
🎥 Top 3 most popular movies

⭐ Highest-rated movies:-
🎬 Movies by specific directors
📊 Genre-wise movie count
📈 Average rating by genre
🏆 Most successful directors
